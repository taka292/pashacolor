# パシャから - 色がテーマのお出かけ共有アプリ 🎨

## 📖 概要

**パシャから**は、毎日出題される色のお題に合わせて写真を撮影・投稿する、色をテーマにしたお出かけ共有アプリです。

日常の中で色を意識することで、いつもの風景が新鮮に見え、お出かけがもっと楽しくなります。集めた色でカラーパレットを完成させる達成感も魅力の一つです。

### 🎯 コンセプト

- **毎日の色のお題**: 12色の色相環から毎日1色がランダムに出題
- **色を探す楽しさ**: 「今日は赤！」と意識して街を歩くと、新しい発見がある
- **想い出の可視化**: 投稿した色でカラーパレットが埋まり、視覚的に記録が残る
- **カジュアルな記録**: 写真なしでも投稿できるため、気軽に続けられる

### 🎨 ターゲットユーザー

- 休日の過ごし方に悩むカップル
- 日々に彩りが欲しい社会人
- 写真を撮るきっかけが欲しい人
- 日記感覚で思い出を記録したい人

## ✨ 主な機能

### 🎲 毎日のお題生成
- ユーザーごとに独立した色のお題を毎日自動生成
- 過去に出題された色を避けるロジックで重複を防止
- ユーザーの進捗に応じたパレットから出題

### 🎨 マルチパレットシステム
- **基本パレット**: 色相環の基本12色から始める
- **宝石パレット**: 前のパレットをコンプリートすると解放
- **花のパレット**: さらにコレクションを広げる
- パレット進捗は視覚的に表示され、達成感を演出

### 📸 柔軟な投稿機能
- 写真付き投稿（JPEG/PNG/WebP、最大10MB）
- 写真なしでも説明文のみで投稿可能
- GPS座標の自動取得または場所名の手動入力
- 色の選択は円形の色相環UIで直感的に操作

### 🗺️ 位置情報管理
- ブラウザのGeolocation APIで位置情報を取得
- プライバシー重視（自分の投稿のみ閲覧可能）
- 将来的にマップ表示機能を実装予定

### 🌈 カラーパレット可視化
- 投稿した色で円形の色相環が埋まっていく
- 未投稿の色はグレーアウト表示
- 色をクリックするとその色の投稿一覧を表示
- パレットごとの進捗率を確認可能

## 🎯 技術的な特徴・工夫点

### 1. ユーザーごとの独立したお題システム
```ruby
# app/models/daily_theme.rb
def self.today_theme(user)
  # ユーザーのアクティブパレットに基づいて
  # 過去の履歴を考慮した重複のないお題を生成
end
```
- 全ユーザー共通ではなく、各ユーザーの進捗に応じたお題を生成
- パレットサイズに応じた日数で重複を回避

### 2. オンデマンド生成によるシンプルな設計
- バッチジョブを使わず、アクセス時にお題を生成
- バックグラウンドジョブの管理が不要で、サーバーコストを削減
- Rails標準のActive Recordで完結

### 3. 段階的に解放されるパレットシステム
```ruby
# app/models/palette_progress.rb
def check_completion!
  # 全色を投稿したら次のパレットを解放
  if palette_colors.all? { |color_id| posted_colors.include?(color_id) }
    complete!
    unlock_next_palette!
  end
end
```
- ゲーミフィケーション要素でユーザーのモチベーションを維持
- 段階的な達成感を提供

### 4. パフォーマンスを意識したクエリ設計
- N+1クエリの回避（`includes`、`joins`の活用）
- 適切なインデックス設定
- ユーザースコープでのデータ分離

### 5. モバイルファーストのUI/UX
- 円形の色相環UIで直感的な色選択
- タッチ操作に最適化されたインターフェース
- レスポンシブデザインで全デバイスに対応
